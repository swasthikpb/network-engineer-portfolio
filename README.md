# Swasthik — Network Engineer Portfolio

A simple professional portfolio for Junior / L1 Network Engineer applications.

## Included
- Cisco routing & switching
- VLAN and inter-VLAN routing
- FortiGate firewall lab
- EVE-NG practical labs
- Network troubleshooting
- IP camera / RTSP networking
- CCNA certification
- Junior Network Engineer experience

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
